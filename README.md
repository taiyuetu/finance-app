# 真好管账（Electron 桌面应用）

纯本地存储的个人财务管理桌面软件，无任何第三方运行时依赖（图表为自研 Canvas 实现）。

## 功能

- 📊 **总览**：总资产、本月收入/支出（含环比）、**年度收入 / 年度支出 / 下月应还**卡片，近 6 个月收支柱状图、本月支出构成环形图、预算执行、最近交易，以及**负债面板**（总负债、净资产、本月应还、还款提醒、各平台还款进度）
- 📝 **交易记录**：记账（支出/收入）、编辑、删除、按月份/类型/分类筛选、关键字搜索、合计统计
- 📥 **导入账单**：导入**支付宝 / 微信支付 / 各银行流水**的 CSV 账单，自动识别格式与来源、判断收入支出、按关键词匹配分类；导入前逐条预览（类型 / 分类 / 勾选均可改），**自动查重**（已存在、文件内重复、疑似重复默认不勾选），不计收支（自转账、余额充值）与已关闭的交易默认跳过；**还款类自动计为支出，退款与收益发放类自动计为收入**；UTF-8 / GBK 编码均可，文件仅在本机解析
- 💼 **预算**：按分类设置月度预算，实时进度条，超 80% 预警、超 100% 红色告警
- 💳 **负债**：欠款平台 / 欠债日期 / **首期应还日期（按欠债日期 + 1 个月自动生成，可改）** / 还款期数 / 总金额 / **年利率** / **还款方式**（面板下拉选择，非 tab）；还款方式支持**等额本金**（每期归还本金固定不变，利息随剩余本金递减，每期应还逐月下降）、**等额本息**（每期还款本金+利息总额固定，由年利率 + 期数自动算出每期应还）、**按日计息**（借呗/花呗口径：每期本金固定，利息 = 剩余本金 × 日利率 × 当期实际天数，首期天数按放款日→首期还款日实算，适合对照平台账单）、**每期最低还款**（信用卡按最低比例递减，按年利率计息）、**先息后本还款**（每期只还利息，末期还本）与**民间借贷**（约定还款日一次性还本付息，年利率为 0 即无息，有利率则按「本金 × 年利率 × 实际天数 ÷ 365」计息，无需分期）；每期应还金额全部自动计算并实时预览；**标记还款仅开放至本月 + 下月**（更早的逾期期次可直接标记，更往后的期次显示「🔒 未到还款期」）；**⏩ 提前结清**：一次性归还剩余本金 + 已产生利息（未来期次不计息，同步生成一笔「还款」支出，可撤销）；各平台应还明细表含**下期应还**（金额 + 日期）与**已还金额**（现金 + 进度）列，配合每期应还明细、剩余应还、全部应还总金额合计一览无余；逾期与 7 天内到期自动提醒，30 天还款计划
- ⚙️ **设置**：**分类管理**（支出/收入分类可新增、重命名、删除，重命名自动同步历史记录与预算，删除不丢记录）、导入账单 CSV、导出 CSV（交易记录 + 负债明细）、载入示例数据、清空数据、数据文件路径
- 🔒 安全：`contextIsolation` + `sandbox`，数据仅保存在本机 userData 目录的 JSON 文件
- ⌨️ 快捷键：`Ctrl+N` 记一笔，`Enter` 保存，`Esc` 关闭弹窗

## 🤖 MCP 服务器（AI Agent 接入）

内置一个独立的 [MCP](https://modelcontextprotocol.io) 服务器（`mcp-server.js` + `finance-core.js` 及其依赖已随安装包内置），让 Claude Desktop / Claude Code / Cursor / pi 等 AI Agent 直接查询账本、记账、管理预算与负债，读写与应用完全同一份 `finance-data.json`。

**18 个工具**：

| 类别 | 工具 |
| --- | --- |
| 查询 | `get_summary` 总览（资产/收支/预算/负债）、`list_transactions` 交易查询、`list_categories` 分类、`get_budgets` 预算执行、`list_debts` 负债列表、`get_debt_schedule` 还款计划、`get_data_path` 数据文件路径 |
| 记账 | `add_transaction` / `update_transaction` / `delete_transaction`（删除还款交易会同步撤销还款标记，与应用一致） |
| 预算 | `set_budget` / `delete_budget` |
| 负债 | `add_debt` / `update_debt` / `delete_debt`、`mark_repayment` 标记还款（自动生成「还款」支出交易）、`undo_repayment` 撤销还款、`settle_debt` 提前结清（支持先 `preview`） |

**启动方式**：

```bash
npm run mcp                    # stdio 传输（本地客户端拉起，推荐）
npm run mcp:http               # Streamable HTTP：http://127.0.0.1:3721/mcp
node mcp-server.js --http 3721 --host 0.0.0.0 --token 密码   # 局域网/远程 + Bearer 鉴权
FINANCE_DATA_FILE=/path/to/finance-data.json node mcp-server.js  # 指定数据文件（自测/多账本）
```

**客户端配置示例**（stdio，二选一）：

① 源码目录运行（开发机，需已 `npm install`）：

```json
{
  "mcpServers": {
    "finance-app": {
      "command": "node",
      "args": ["C:/Users/hdmso/finance-app/mcp-server.js"]
    }
  }
}
```

② **安装版运行（目标电脑无需安装 Node.js）**：安装包已内置 MCP 服务器，通过 `ELECTRON_RUN_AS_NODE=1` 让应用自带的 Electron 当 Node 运行时使用。默认安装路径（当前用户安装）为 `C:\Users\<用户名>\AppData\Local\Programs\真好管账`：

```json
{
  "mcpServers": {
    "finance-app": {
      "command": "C:\\Users\\<用户名>\\AppData\\Local\\Programs\\真好管账\\真好管账.exe",
      "args": ["C:\\Users\\<用户名>\\AppData\\Local\\Programs\\真好管账\\resources\\app\\mcp-server.js"],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}
```

若安装时改了目录或装到了整机（Program Files），把上面两个路径改成实际安装位置即可；安装目录里可直接搜索 `mcp-server.js` 定位。

支持 Streamable HTTP 的客户端直接填 URL `http://127.0.0.1:3721/mcp`（或带 token 时附 `Authorization: Bearer <密码>` 头）。

**特性与安全**：

- 🔁 **实时同步**：应用运行时，MCP 写入账本后界面会自动刷新（有弹窗打开时延迟到关闭后）；应用未运行时也能直接使用。
- 🔒 **写入安全**：原子写入 + 串行化读改写；对外监听默认仅 127.0.0.1，对外暴露请务必加 `--token`；stdio 模式无需鉴权（由客户端进程隔离）。
- 🧮 **计算同构**：还款计划（等额本息/最低还款/先息后本/民间借贷）、提前结清利息计算与应用内完全一致。
- 🧪 自测：`npm run test:mcp`（在临时账本上跑完整协议与工具用例，不碰真实数据）。

## 导入账单（自动记账）

入口：侧边栏「📥 导入账单」，或交易记录页 / 设置页的「导入账单」按钮；支持点击选择文件与**拖拽文件**两种方式。

- **支持的来源**：支付宝（新旧版账单格式均可）、微信支付账单、各银行网银 / 手机银行导出的 CSV 流水（含「借贷方向」列、「借方/贷方发生额」两列等常见版式）。
- **自动处理**：编码识别（UTF-8 / GBK / GB18030 / UTF-16）、表头识别（按关键词匹配列，不写死列序）、收支方向判定（方向列 → 借贷金额列 → 金额正负 → 摘要关键词）、分类自动匹配（美团→餐饮、滴滴→交通、工资发放→工资、结息→投资等，兜底到「其他」）。
- **查重**：与账本完全相同（日期 + 类型 + 金额 + 备注）标记「已存在」，同一文件内重复标记「文件内重复」，同日同金额标记「疑似重复」——均**默认不勾选**，避免重复记账；重复导入同一账单不会产生重复记录。
- **默认跳过但可见**：「收/支 = 其他 / /」中真正的自转账、余额充值等不计收支，以及交易关闭 / 失败 / 含退款状态的记录默认不勾选，可在预览中逐条手动开启（含退款状态的记录会预填为收入）。
- **特殊条目自动判向**：「收/支 = 其他 / /」里的**还款类**（还信用卡、还花呗、还借呗等）判为**支出**，**退款类**（退款、退货、理赔等）与**收益发放类**（收益、分红、利息、结息等）判为**收入**，这些条目可直接导入。
- **预览编辑**：每行可改「支出 / 收入 / 不导入」与分类，支持全选、只看已勾选 / 只看疑点的筛选，大文件分页显示。
- 导入的记录带来源标记（src），与手动记账完全同构：进入总览统计、收支柱状图、支出构成、预算执行，并可参与负债还款联动；导入后可在「交易记录」中继续编辑或删除。

## 负债与其它模块的联动

- **记还款 → 交易记录**：在总览或负债页点「记还款 / 标记还款」，会自动新增一笔分类为「还款」的支出（备注如 `支付宝借呗 第7期`），因此这笔钱会同步计入本月支出、支出构成环形图、预算执行与总资产。
- **交易记录 → 负债**：在交易记录里删除一笔还款支出，对应期数的还款标记会一并撤销；反之在负债页「撤销还款」，对应的交易也会删除。
- **总览面板**：展示总负债（剩余应还）、净资产（总资产 − 总负债）、本月应还、逾期/7 天内还款提醒，以及每个平台的还款进度条。
- **导出**：设置页或负债页可分别导出「交易记录 CSV」与「负债明细 CSV」（含每期应还计划表）。

## 数据存储

数据文件位于（目录名取自应用名 productName）：

```
Windows: %APPDATA%/真好管账/finance-data.json
macOS:   ~/Library/Application Support/真好管账/finance-data.json
```

可直接备份该 JSON 文件，或使用应用内的「导出 CSV」。
